CodeIgniter 4에서 JSON 파일로 데이터 관리하기

DB 없이도 간단한 프로젝트에서 데이터를 관리할 수 있다. CodeIgniter 4의 writable 디렉토리를 활용해 JSON 파일 기반 CRUD를 구현하는 방법을 정리한다. 핵심은 JsonStore 같은 라이브러리 클래스를 하나 만들어서 read/write를 추상화하는 것이다. file_get_contents + json_decode로 읽고, json_encode + file_put_contents로 쓴다. 장점은 DB 설정이 필요 없고 배포가 간단하다는 것. 단점은 동시 쓰기에 취약하고 대용량 데이터에 부적합하다는 것. 소규모 프로젝트나 프로토타입에 적합한 패턴이다.
