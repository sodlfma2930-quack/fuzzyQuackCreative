WebAssembly(Wasm) 정리 — 브라우저에서 C++과 Rust가 돌아가는 시대

JavaScript가 웹의 유일한 언어이던 시대는 끝났다. WebAssembly(줄여서 Wasm)는 브라우저에서 네이티브에 가까운 속도로 코드를 실행할 수 있게 해주는 기술이다. C, C++, Rust, Go 등으로 작성한 코드를 브라우저에서 바로 돌릴 수 있다. ## WebAssembly란? Wasm은 웹 브라우저를 위한 저수준 바이너리 포맷이다. JavaScript처럼 소스 코드를 해석하는 게 아니라, 미리 컴파일된 바이너리를 실행한다. 그래서 JavaScript보다 훨씬 빠르고, 네이티브 앱에 가까운 성능을 낸다. W3C 공식 웹 표준이며, Chrome, Firefox, Safari, Edge 모든 주요 브라우저에서 지원한다. ## 왜 중요한가? 기존에 웹에서 할 수 없던 것들이 가능해진다. 게임 엔진: Unity, Unreal Engine이 Wasm으로 브라우저에서 3D 게임을 돌린다. 영상/이미지 편집: Figma, Photoshop Web이 Wasm으로 구현. 설치 없이 브라우저에서 전문 툴 사용. 코드 에디터: VS Code Web(vscode.dev)이 Wasm으로 언어 서버를 브라우저에서 실행. AI 추론: TensorFlow.js + Wasm 백엔드로 브라우저에서 ML 모델 실행. 서버 없이 추론 가능. 데이터베이스: SQLite가 Wasm으로 포팅되어 브라우저에서 SQL 쿼리 실행 가능. 이전에는 "설치하세요"라고 했던 것들이 "링크 열면 됩니다"로 바뀐다. ## 어떻게 동작하나? 1. C/C++/Rust 등으로 코드를 작성한다 2. Emscripten(C/C++) 또는 wasm-pack(Rust)으로 .wasm 파일로 컴파일한다 3. JavaScript에서 .wasm 파일을 로드하고 함수를 호출한다 Rust 예시: #[wasm_bindgen] pub fn fibonacci(n: u32) -> u32 { match n { 0 => 0, 1 => 1, _ => fibonacci(n - 1) + fibonacci(n - 2), } } JavaScript에서 호출: import init, { fibonacci } from './pkg/my_wasm.js'; await init(); console.log(fibonacci(40)); // 네이티브 속도로 실행 같은 피보나치를 JavaScript로 돌리면 수 초 걸리지만, Wasm으로 돌리면 수십 밀리초에 끝난다. ## Wasm의 활용 범위 — 브라우저 밖으로 2026년 현재, Wasm은 브라우저 밖에서도 주목받고 있다. WASI(WebAssembly System Interface)는 Wasm을 서버와 엣지에서 실행할 수 있게 해주는 표준이다. Docker의 공동 창업자가 "Wasm이 2008년에 있었다면 Docker를 만들 필요가 없었을 것"이라고 말한 적이 있다. Cloudflare Workers: 엣지에서 Wasm 실행. 전 세계 300개 이상 PoP에서 밀리초 단위 응답. Fastly Compute: Wasm 기반 서버리스. 콜드 스타트가 마이크로초 단위. WasmCloud: 마이크로서비스를 Wasm 컴포넌트로 구성. 언어 무관. Docker + Wasm: Docker가 Wasm 컨테이너를 공식 지원하기 시작. ## JavaScript와의 관계 Wasm은 JavaScript를 대체하려는 게 아니다. UI 렌더링, DOM 조작, 이벤트 처리는 여전히 JavaScript가 담당한다. Wasm은 연산 집약적인 작업(이미지 처리, 암호화, 물리 엔진, AI 추론)을 맡는다. 즉, JavaScript가 지휘자라면 Wasm은 오케스트라의 연주자다. 둘이 협력해서 웹의 한계를 넓히는 구조다. ## 시작하기 Rust + Wasm이 현재 가장 생태계가 잘 갖춰져 있다. cargo install wasm-pack wasm-pack new my-project wasm-pack build --target web 이 세 줄이면 Wasm 프로젝트가 만들어지고 빌드된다. Rust가 부담스러우면 AssemblyScript도 좋은 선택이다. TypeScript와 거의 같은 문법으로 Wasm을 만들 수 있다. ## 앞으로의 전망 Wasm Component Model이 안정화되면, 서로 다른 언어로 작성된 Wasm 모듈들이 레고 블록처럼 조합될 수 있다. Rust로 만든 이미지 처리 모듈 + Python으로 만든 ML 모듈을 하나로 엮는 게 가능해진다. 웹의 다음 10년을 이끌 기술 중 하나로 Wasm은 반드시 주목해야 한다.
