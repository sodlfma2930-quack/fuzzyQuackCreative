Claude Code 원격 에이전트로 블로그 자동 포스팅하는 원리

매일 아침 자동으로 블로그 글이 올라오는 원리가 궁금할 수 있다. 이건 Claude Code의 Remote Agent(원격 에이전트) 기능을 활용한 것이다. ## 동작 구조 1. Anthropic 클라우드에 cron 스케줄을 등록한다 (예: 매일 UTC 0시 = KST 오전 9시) 2. 스케줄 시간이 되면 원격 에이전트가 독립된 샌드박스 환경에서 실행된다 3. 에이전트가 GitHub 레포를 클론하고, 기존 posts.json을 읽는다 4. 이미 있는 글과 중복되지 않는 새로운 기술 주제를 선택해 글을 작성한다 5. posts.json에 새 글을 추가하고, git commit + push 한다 6. 로컬에서 git pull 하면 새 글이 반영된다 ## 핵심 개념 원격 에이전트는 로컬 머신이 아닌 Anthropic의 클라우드 인프라에서 실행된다. 그래서 내 컴퓨터가 꺼져 있어도 스케줄대로 동작한다. 설정에 필요한 것은 3가지다: - cron_expression: 실행 주기 (5-field cron, UTC 기준) - git_repository: 클론할 레포 URL - prompt: 에이전트에게 줄 작업 지시서 ## 설정 예시 cron_expression: "0 0 * * *" → 매일 UTC 0시 (KST 9시) model: claude-sonnet-4-6 allowed_tools: Bash, Read, Write, Edit 프롬프트가 가장 중요하다. 에이전트는 이전 대화 맥락이 없으므로, 어떤 파일을 읽고, 어떤 형식으로 쓰고, 어떻게 커밋하는지를 프롬프트 안에 모두 명시해야 한다. 이 방식의 장점은 서버 없이도 자동화된 콘텐츠 파이프라인을 만들 수 있다는 것이다. CI/CD의 scheduled job이나 GitHub Actions의 cron과 비슷하지만, AI가 콘텐츠를 직접 생성한다는 점이 다르다.
